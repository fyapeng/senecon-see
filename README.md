# 结构估计导论 · 官方配套页面

《结构估计导论》（*Introduction to Structural Estimation*）的展示、配套代码、勘误与版本更新入口。

网站提供书目介绍、前言与目录、版本化教材与习题解答 PDF、配套代码和勘误入口。教材以 LaTeX 书稿为唯一权威来源，计算材料以 Python 实现为唯一权威来源；LaTeX 源码不随 PDF 公开。

## 本地预览

```powershell
npm install
npm run dev
```

## 发布

推送到 `main` 后，GitHub Actions 构建并发布 `dist/client` 到 GitHub Pages。

当前公开版本v2.0.0（2026-09-18）。下载地址统一维护于src/content/release.js；教材与解答CC BY-NC 4.0，原创配套代码MIT，第三方适配另保留原许可。Release自动生成的Source code档案仅为网站源码。
